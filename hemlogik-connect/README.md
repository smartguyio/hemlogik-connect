# Hemlogik Connect

Connects Home Assistant securely to Hemlogik for remote access, monitoring and management.

See [DOCS.md](DOCS.md) for installation, configuration, and troubleshooting.

This folder is mirrored to the public [smartguyio/hemlogik-connect](https://github.com/smartguyio/hemlogik-connect)
repository, which is what installers actually add to Home Assistant - see that repository's own
README for the add-on-repository install steps. The full technical architecture and local-dev
docs live in this (private) repository's `docs/hemlogik-connect-architecture.md` and
`docs/hemlogik-connect-local-dev.md`, not in the public mirror.
